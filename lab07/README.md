## Доп объяснения и ответы на вопросы:

* **Разница между `return` и `print()`:** Инструкция `return` возвращает значение из функции в то место, откуда она была вызвана, сохраняя результат для дальнейших вычислений в программе. Функция `print()` лишь выводит информацию на экран терминала для пользователя и не возвращает данных (возвращает `None`).

* **Локальные переменные и параметры:** Параметры — это переменные, принимающие значения при вызове функции. Локальные переменные создаются и используются исключительно внутри тела функции. Ни параметры, ни локальные переменные недоступны за пределами своей функции.

* **Назначение `assert`:** Оператор `assert` проверяет истинность выражения. Если условие истинно, программа продолжается без вывода текста; если условие ложно, вызывает исключение `AssertionError`, сигнализирующее об ошибке в коде.

* **Тест для обнаружения ошибки:** Если в `sum_digits(number)` забыть взять модуль `abs(number)`, то для отрицательного числа `-507` функция вернёт ошибку, так как не существует числа '-'. Тест `assert sum_digits(-507) == 12` упадет с `AssertionError`, сразу обнаружить ошибку.
