## 🧠 Дополнительные объяснения и ответы на вопросы

* **Какую ошибку выявляет таблица 2x3?**
Таблица 2x3 (2 строки, 3 столбца) показывает, что количество строк и столбцов не равно. Если использовать алгоритмы, предполагающие квадратную матрицу (где `len(matrix) == len(matrix[0])`), или неправильно перепутать индексы строки и столбца при переборе, это приведет к `IndexError` или неверным результатам.
* **Почему нельзя повторять одну изменяемую строку?**
  Конструкция `[[0] * columns] * rows` создает список, где все элементы ссылаются на **один и тот же** внутренний список. При изменении `matrix[0][0]` значение изменится и в `matrix[1][0]`, и во всех остальных строках. Поэтому таблицу нужно создавать через генератор списков: `[[0] * columns for _ in range(rows)]`.

* **Чем копия внешнего списка отличается от копирования строк?**
  `matrix.copy()` копирует только внешний список. Внутренние списки (строки) остаются общими. Изменение `new_matrix[0][0]` изменит и `matrix[0][0]`. Для полной независимости нужно копировать каждую строку: `[row.copy() for row in matrix]`. Именно так сделано в функции `transform`.

* **Как работает `diagonal_pattern`?**
  Создается квадратная матрица, заполненная нулями. Затем вложенный цикл перебирает индексы `row` и `column`. Если `row == column` (главная диагональ), оставляем `0`. Если `row < column` (выше диагонали), ставим `1`. Если `row > column` (ниже диагонали), ставим `2`.

* **Рекурсия в `factorial`.**
  Базовый случай: `if number == 0: return 1`. Шаг рекурсии: `return number * factorial(number - 1)`. Функция вызывает саму себя до тех пор, пока не дойдет до нуля. Глубина рекурсии для чисел $0\text{–}20$ безопасна для Python (стандартный лимит — 1000 вызовов).
