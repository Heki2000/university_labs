## 🔍 Проверки и результаты выполнения заданий

### 1. `time_parts.py` (Перевод времени)

* **Входные данные:** `0`, `59`, `60`, `3671`, `3600`.

* **Ожидаемый / Фактический результат:**

  * Для `0` с -> `0 ч 0 мин 0 с`

  * Для `59` с -> `0 ч 0 мин 59 с`

  * Для `60` с -> `0 ч 1 мин 0 с`

  * Для `3671` с -> `1 ч 1 мин 11 с`

  * Для `3600` с -> `1 ч 0 мин 0 с`

* **Дополнительная проверка:** Проверка при вводе значений, превышающих 24 часа (например, `86400` с -> часы корректно превышают 23).

### 2. `purchase.py` (Стоимость покупки)

* **Входные данные:**

  * Цена: `45`, Количество: `3`, Внесено: `200`

* **Ожидаемый / Фактический результат:**

  * Стоимость: `135` руб., сдача: `65` руб.

* **Дополнительная проверка:**

  * Ввод с нулевым количеством: цена `45`, количество `0`, внесено `100` -> стоимость `0`, сдача `100`.

### 3. Предсказание результата

* **2 + 3 * 4** | `Ожидамый результат и фактический: 14` (сначала выполняется умножение, после сложение)

* **( 2 + 3 ) * 4** | `Ожидамый результат и фактический: 20` (скобки ставят в приоритете сложение, после умножение)

* **( 17 // 5 )** | `Ожидамый результат и фактический: 3` (целочисленное деление, 17, делённое на 5, даёт 3 и в остатке 2 => // вернёт 3)

* **( 17 % 5 )** | `Ожидамый результат и фактический: 2` (остаток от деления, остальное описано в пункте выше)

* **(-7 // 2)** | `Ожидамый результат и фактический: -4` (целочисленное деление всегда округляет "вниз", поэтому при деление -7 на 2 в результате получится -3.5, при целочисленном делении даёт -4)


### 4. `variant.py` (Расчет заказа: Вариант №9 — Билеты и пачки)

* **Позиции варианта:** Общий объем — «Количество билетов», вместимость единицы — «Билетов в пачке».

* **Пример ручного расчета для проверки:**

  ```
  - Вариант: Общий объём билетов: 21, вместимость пачки: 10
  - Полностью заполненных пачек: 2
  - Остаток билетов (не вошедших в полные пачки): 1
  - Минимальное число пачек для размещения всех билетов: 3
  
  ```

* **Дополнительные проверки:**

  * Проверка с нулевым объемом (`0` билетов, пачка по `10`) -> полных `0`, остаток `0`, всего `0`.

  * Проверка без остатка (`20` билетов, пачка по `10`) -> полных `2`, остаток `0`, всего `2`.

### Доп объяснения и ответы на вопросы:

* **Отличие `/` от `//`:** Оператор `/` выполняет обычное деление с плавающей точкой (`float`), возвращая дробный результат (например, `7 / 2 == 3.5`). Оператор `//` выполняет целочисленное деление (деление с округлением вниз до ближайшего целого), отбрасывая остаток (например, `7 // 2 == 3`, а `-7 // 2 == -4`).

* **Смысл остатка (`%`):** Операция взятия остатка от деления возвращает то, что «не поместилось» целое число раз в делитель (например, `7 % 2 == 1`, так как `3 * 2 + 1 = 7`). Это крайне полезно для перевода единиц измерения (секунд в минуты, остатка предметов по коробкам и т.д.).

* **Неточность `float`:** Тип `float` хранит вещественные числа в двоичном виде, из-за чего многие десятичные дроби (например, `0.1 + 0.2`) представляются приближенно (получается `0.30000000000000004`). Форматирование вывода (например, `:.2f`) лишь визуально округляет отображаемое число на экране, но не меняет само внутреннее приближенное значение в памяти компьютера.
