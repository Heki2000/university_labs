## 📂 Структура лабораторной работы

В лабораторной работе представлены следующие файлы:

1. `main.py` — основная программа. Выполняет надёжный ввод положительного целого числа, читает матрицу из `matrix.txt`, вычисляет суммы строк и столбцов, а также результат индивидуального варианта. После успешной проверки входных данных создаёт `report.txt`.
2. `files_lab.py` — модуль обработки текстовых файлов:
   * `read_matrix(path)` — читает матрицу из UTF-8-файла и проверяет формат данных;
   * `selected_sum(matrix)` — вычисляет сумму элементов последней строки. Для пустой матрицы возвращает `0`.
3. `table.py` — модуль функций для работы с таблицами:
   * `row_sums(matrix)` — возвращает список сумм строк;
   * `column_sums(matrix)` — возвращает список сумм столбцов;
   * `diagonal_pattern(size)` — создаёт квадратную таблицу с диагональным узором;
   * `transform(matrix)` — заменяет элементы, кратные 3, числом `3`, не изменяя исходную матрицу;
   * `factorial(number)` — вычисляет факториал рекурсивно;
   * `factorial_iterative(number)` — вычисляет факториал итеративно.
4. `test_files.py` — автоматические проверки чтения матрицы и обработки ошибочных данных.
5. `matrix.txt` — входной файл с исходной матрицей.
6. `report.txt` — пример сформированного программой отчёта.
7. `README.md` — описание работы, инструкции по запуску и результаты проверок.

## 📄 Формат входного файла

Файл `matrix.txt` должен быть сохранён в кодировке UTF-8 и иметь следующий формат:

- Первая строка содержит два положительных целых числа: количество строк и количество столбцов.
- Далее записывается указанное количество строк матрицы.
- В каждой строке должно находиться ровно указанное количество целых чисел.
- Пустой файл, некорректный заголовок, нечисловые значения, пустые строки и неправильное количество строк или столбцов считаются ошибками.
- Один обычный перевод строки после последней строки данных допускается.

Содержимое используемого файла `matrix.txt`:

```text
2 3
1 -2 3
4 0 -6
```

После чтения функция `read_matrix()` возвращает матрицу:

```python
[[1, -2, 3], [4, 0, -6]]
```

## 🧠 Дополнительные объяснения

* **Зачем используется `with open()`?** Контекстный менеджер автоматически закрывает файл после завершения блока, в том числе при возникновении исключения.
* **Почему указана кодировка `encoding="utf-8"`?** Она обеспечивает корректное чтение и запись текста, в том числе русских символов.
* **Чем ошибка формата отличается от ошибки доступа?** `ValueError` возникает, когда содержимое файла не соответствует ожидаемой структуре. `FileNotFoundError` и другие `OSError` связаны с открытием или доступом к файлу. `UnicodeError` сообщает о проблеме декодирования текста.
* **Почему `UnicodeError` обрабатывается раньше `ValueError`?** `UnicodeError` является подклассом `ValueError`, поэтому более конкретное исключение нужно перехватить раньше общего.
* **Почему `report.txt` открывается для записи только после проверки матрицы?** Если чтение или проверка входного файла завершится ошибкой, блок записи не выполнится и прежний отчёт не будет перезаписан.
* **Как работает индивидуальный вариант №9?** Выражение `matrix[-1]` обращается к последней строке матрицы, а `sum(matrix[-1])` вычисляет сумму всех её элементов. Для матрицы из примера: `4 + 0 + (-6) = -2`.
