## Доп объяснения и ответы на вопросы:

* **Отличие `append()` от присваивания по индексу:** Метод `append(element)` динамически добавляет новый элемент в конец списка, увеличивая его длину на 1. Присваивание по индексу (`items[i] = value`) меняет значение уже существующего элемента по указанному индексу и вызовет ошибку `IndexError`, если индекс выйдет за пределы списка.

* **Отличие `sorted()` от `.sort()`:** Функция `sorted(items)` создает и возвращает **новый** отсортированный список, не изменяя исходный. Метод `items.sort()` сортирует список «на месте» (in-place), изменяя порядок элементов в исходном объекте и возвращая `None`.

* **Сохранение исходного списка во 2 задании:** Чтобы изменить значения или сформировать новый массив без порчи исходных данных, используется либо метод `.copy()` для явного поверхностного копирования (`copy_list = items.copy()`), либо создание абсолютно нового списка через генератор/цикл (например, `new_list = [abs(x) for x in items]`), что оставляет оригинальный список `items` нетронутым.

* **Алгоритм сохранения уникальных элементов с сохранением порядка:** Для удаления дубликатов без использования множеств `set` создается новый пустой список. Далее производится обход исходного списка: если текущий элемент еще не содержится в новом списке (`if item not in unique_numbs`), он добавляется через `.append()`. Это позволяет избавиться от повторов и сохранить порядок первого появления каждого элемента.
