## 📂 Структура лабораторной работы

В данной лабораторной работе (`lab05`) представлены следующие файлы с исходным кодом:

1. `normalize.py` — нормализация текста: удаление крайних пробелов, замена внутренних последовательностей пробелов одним пробелом с подсчетом длины и количества слов.
2. `palindrome.py` — проверка строки на палиндром с игнорированием регистра и обычных пробелов с помощью среза `[::-1]`.
3. `replace.py` — замена всех двоеточий на дефисы с предварительным подсчетом их количества.
4. `variant.py` — очистка слов от знаков пунктуации по краям, приведение к нижнему регистру и отбор слов, не содержащих букву «а» (индивидуальный вариант №9).
5. `Dop.py` — дополнительное задание: проверка строки на палиндром с использованием цикла и двух указателей (без использования срезов).

## Доп объяснения и ответы на вопросы:

* **Неизменяемость строк (immutability):** В Python строки являются неизменяемым типом данных (`str`). Это означает, что любые строковые методы (например, `.lower()`, `.replace()`, `.strip()`) не меняют исходную строку в памяти, а возвращают новую созданную строку.
* **Отличие слова от подстроки:** Подстрока — это любая непрерывная последовательность символов внутри строки (например, `"мя"` в `"армия"`). Слово — это логическая единица текста, выделенная с помощью разделителей (пробелов или знаков пунктуации).
* **Правила обработки пунктуации:** Поведение алгоритма (например, при проверке палиндромов) сильно зависит от того, учитываются ли знаки препинания. Поэтому правила (удалять ли пунктуацию, очищать ли только края или всю строку) необходимо явно задавать на этапе проектирования до написания кода.
* **Палиндром без срезов:** Альтернативный способ проверки использует цикл сверки символов поиндесно. Это дает тот же результат, что и сравнение со срезом `[::-1]`.
