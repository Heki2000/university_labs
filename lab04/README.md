## 📂 Структура лабораторной работы

В данной лабораторной работе (`lab04`) представлены следующие файлы с исходным кодом:

1. `range_numbers.py` — вывод чисел от `a` до `b` включительно по возрастанию, убыванию или одного числа при равенстве.

2. `statistics.py` — расчет суммы, числа положительных значений и максимума для введенных `n` целых чисел.

3. `positive_input.py` — повторный запрос целого числа до получения положительного, с выводом квадрата и количества отклонённых попыток.

4. `variant.py` — нахождение количества и суммы ненулевых значений в потоке из `n` целых чисел.

5. `simple_number.py` — проверка целого числа `n >= 2` на простоту путем перебора делителей до квадратного корня из `n`.

## Доп объяснения и ответы на вопросы:

* **Выбор `for` и `while`:** `for` используется для перебора готовой последовательности значений (например, `range`), а `while` выполняет тело цикла, пока его условие остается истинным.

* **Завершение цикла:** Для корректного завершения `while` переменная из условия должна изменяться внутри цикла, либо необходимо использовать досрочное прерывание `break`.

* **Накопители и счётчики:** В цикле от 1 до 4 накопитель `total = 0` последовательно принимает значения: до итерации `0, 1, 3, 6`, после итерации `1, 3, 6, 10`.

* **Особенность `range(a, b)`:** Данная функция имеет шаг 1 по умолчанию и не включает правую границу. Если `a > b`, функция выдаст пустую последовательность, поэтому для убывающего диапазона требуется явное ветвление в коде.
