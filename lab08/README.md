## 🧠 Дополнительные объяснения и ответы на вопросы

* **Почему запись удобно представить словарём (задание 3).** Запись — это набор именованных полей. Словарь хранит данные «по имени», а не «по позиции», поэтому `record["hours"]` читается однозначно. Словарь изменяем: можно поменять `hours` или добавить `completed`, не пересоздавая объект. Ключи сами документируют назначение значения. Кортеж в этом задании используется как краткая пара значений `(title, hours)`, удобная для распаковки.

* **Поведение `.get()`.** `record.get("hours", 0)` возвращает значение по ключу, если он есть, иначе — второй аргумент (`0`). В `word_counts` и `totals_by_category` это позволяет в одну строку накапливать счётчики и суммы. Если ключа ещё нет — начинаем с нуля, если есть — прибавляем к текущему значению.

* **Почему множество сортируют перед выводом.** У `set` нет индексов и гарантированного порядка обхода. Чтобы результат был воспроизводим, множество прогоняют через `sorted(...)`. В `common_topics` и `all_topics` операции `&` и `|` дают множество, затем `sorted` превращает его в отсортированный список.

* **Выбор структуры для каждого задания.**
  * **Задание 1:** `dict`, так как нужно соответствие «слово -> количество» и быстрый доступ.
  * **Задание 2:** `set` для операций пересечения и объединения без дублей.
  * **Задание 3:** `dict` для именованных полей записи и `tuple` для фиксированной пары.
  * **Индивидуальный вариант:** `dict` для накопления сумм по категориям, список `records` только читается.

* **Как обеспечена неизменность входных данных.** `totals_by_category` и `titles_in_category` работают только «на чтение»: перебирают `records`, читают поля, складывают результаты в новый словарь или список. Поэтому `assert records == snapshot` в `test_collections.py` проходит без ошибок.

* **Назначение `assert`.** `assert условие` проверяет истинность выражения. Если истинно — программа продолжается, если ложно — выбрасывается `AssertionError`. В тестах это основной инструмент проверки. Отключается при запуске Python с флагом `-O`, поэтому в рабочем коде для проверки ввода используют явные исключения.

* **Как работает дополнительное задание (сортировка и `key`).** Функция `sorted()` по умолчанию сортирует по возрастанию, сравнивая элементы напрямую. Аргумент `key` позволяет передать функцию (в нашем случае `lambda x: (-x[1], x[0])`), которая для каждого элемента возвращает то, по чему нужно сравнивать. Для пары `(category, total)` мы возвращаем кортеж `(-total, category)`. Python сравнивает сначала первые элементы кортежей (минус суммы). Из-за минуса большая сумма становится меньшим числом, что дает сортировку по убыванию. Если суммы равны, Python переходит ко второму элементу — названию категории, и сортирует их по возрастанию (по алфавиту).
