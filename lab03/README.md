## 📂 Структура лабораторной работы

В данной лабораторной работе (`lab03`) представлены следующие файлы с исходным кодом:

1. `minimum.py` — поиск минимального из трех целых чисел с использованием ветвлений (`if`/`elif`/`else`).

2. `calculator.py` — простой калькулятор для вещественных чисел с поддержкой операций `+`, `-`, `*`, `/` и обработкой ошибок.

3. `point.py` — проверка принадлежности точки с координатами `(x, y)` прямоугольнику (`0 <= x <= 5` и `0 <= y <= 3`).

4. `variant.py` — определение категории игрового ресурса по введенному значению от 0 до 100 (индивидуальный вариант №9).

5. `leap_year.py` — дополнительное задание. Определение высокосного года.

## Доп объяснения и ответы на вопросы:

* **Выбор `and` / `or`:** Логический оператор `and` используется, когда все проверяемые условия должны выполняться одновременно (например, проверка попадания точки в диапазон по обеим осям: `0 <= x <= 5 and 0 <= y <= 3`). Оператор `or` применяется, если достаточно выполнения хотя бы одного условия (например, проверка выхода значения за допустимый диапазон баллов).

* **Порядок ветвей в условных операторах:** Цепочка `if-elif-else` проверяет условия последовательно сверху вниз и выполняет тело **только первой** подошедшей ветви. Поэтому важно выстраивать проверки в строгом порядке (например, отсекать критические ошибки или крайние границы в самом начале, а общие случаи оставлять на `elif`/`else`).

* **Поведение при равенстве значений:** При корректной организации строгих (`<`, `>`) и нестрогих (`<=`, `>=`) неравенств граничные значения должны захватываться ровно один раз. Если значения равны граничным точкам интервалов (например, пороги категорий `14` и `15`), условие должно однозначно определять, к какому интервалу относится граница, во избежание пересечений.
